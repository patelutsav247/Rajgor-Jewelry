
# Rajgor Jewelry - Full Stack E-Commerce Website

## About Project
Rajgor Jewelry is a modern and responsive jewellery
e-commerce website where customers can explore
different jewellery collections.

## Features
- Responsive Homepage
- Gold, Diamond and Silver Collections
- Product Listing
- Product Details
- Search and Filter
- Shopping Cart
- Wishlist
- Customer Login and Registration
- Admin Dashboard
- Product Management
- Contact and Enquiry Form

## Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB Atlas
- Mongoose

### Tools
- Visual Studio Code
- Git
- GitHub
- Postman

## Project Structure
- frontend/ - Website Frontend
- backend/ - Server and APIs

## Installation

1. Clone the repository.
2. Open the project in VS Code.
3. Navigate to the backend folder.
4. Run npm install.
5. Configure your .env file.
6. Start the backend using node server.js.
